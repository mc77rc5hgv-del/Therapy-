# images/therapy/

Изображения для раздела «Терапия» (схемы, атласные картинки, скриншоты слайдов и т.д.) кладутся
сюда — та же конвенция `images/<subject>/...`, что в `vmeda-biology-bot`. Путь к файлу указывается
в соответствующем поле `therapy.json` (например, внутри `material[]`), резолвится относительно
`IMAGES_DIR` — см. CLAUDE.md. Пока в этой директории нет реальных изображений: раздел ещё не
получил исходные материалы (слайды/атлас) для переноса.
